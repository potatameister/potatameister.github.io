PaperKnife Privacy Policy

Last updated: October 1, 2026

PaperKnife is built around a simple principle: your files stay on your device, period.

Data Collection

PaperKnife does not collect, store, transmit, or share any personal data, usage data, or user information of any kind.

Zero-Server Architecture

PaperKnife has no backend. There is no server that receives, stores, or forwards your documents, because there is no server at all. Your PDFs are processed on your own device, in memory, by the app itself. Nothing you open, merge, split, compress, or convert is uploaded anywhere.

Local Files Only

Every operation — merging, splitting, compressing, rotating, encrypting, signing, converting between PDF and images, and stripping metadata — happens locally using open-source PDF libraries. The files you process never leave your phone or browser.

Permissions Used

PaperKnife only needs access to the files you explicitly choose to open:

  • File access: To read the PDFs you pick, and to write processed PDFs to the location you choose.
  • No location, camera, microphone, contacts, or background services.

The Web Version

PaperKnife is also published as a website and can be installed as a PWA. The web version is a static app served from GitHub Pages, so opening it is an ordinary request to a web host — unavoidable for anything that runs in a browser. Beyond that, PaperKnife sends nothing about you or your documents anywhere. It has no analytics scripts, no advertising scripts, and no third-party trackers.

Analytics & Tracking

PaperKnife contains no analytics SDKs, no crash reporting services, no advertising networks, and no third-party trackers. There is nothing to opt out of because nothing is collected.

Open Source

PaperKnife is free and open-source under the GNU AGPL v3. Every line of code that touches your files is public, so you can check for yourself instead of taking this page's word for it.

Children's Privacy

PaperKnife does not target children and does not knowingly collect any data from users of any age.

Changes to This Policy

If this policy is ever updated, the change will be posted on this page with a revised "Last updated" date.

Contact

For questions about this privacy policy, open an issue on the GitHub repository.
